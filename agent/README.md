# agent

Chat service in front of the risk classifier for a **FICTIONAL** disease (Velorin-Kessler syndrome). All data is synthetic;
nothing here is medical advice. A person pastes labs and a note as free text; a Strands agent (Claude Haiku 5.5) decides
whether to score it, and the classifier's report is returned unchanged with a plain-language reply.

Written up fully when the service is complete (see `openspec/changes/add-agent-service`).
