Setting: copy_forward. A progress note built by copying the previous visit's note forward and editing it.

Write it as a progress note that mixes routine carried-over boilerplate (reviewed-and-unchanged lines, never naming any medication or condition) with a few updated lines for this visit. If you use "c/o" (complains of) it is only for symptoms that are present or possible, never "c/o denies". The layout, opener, stock lines and markers are set by the style lines. Do not label any value as old, previous or carried over: every value looks current. About 70 to 150 words.
